# gw2_cos_web_admin Frontend Audit - Round 45

## Scope

- `src/pages/RbacRoles/index.tsx`
- `src/pages/Slang/index.tsx`

## Root Cause

- `RbacRoles` 实际上是权限模板页，但首屏没有先解释：
  - 普通角色和超级角色的差异
  - 删除角色的影响范围
  - 这里维护的是角色模板，不是管理员账号本身
- `Slang` 是“黑话条目 + 分组管理”双工作台，但当前页面一进来直接落到 tab 和弹窗，缺少首屏工作语义与摘要信息。
- 两页弹窗入口虽然功能已经稳定，但字段边界提示仍不足，用户需要靠业务经验推断每个字段和操作的影响面。

## Changes

### 1. RBAC 角色页首屏语义前置

- 为 `RbacRoles` 增加页内说明，明确：
  - 普通角色依赖权限勾选
  - 超级角色自动放行
  - 删除角色会影响绑定该角色的管理员
- 增加 4 张摘要卡，前置展示：
  - 角色总量
  - 超级角色
  - 已配权限角色
  - 权限模块数
- 为创建 / 编辑角色弹窗增加：
  - 更明确的占位文案
  - 权限配置提示
  - 更宽的表单宽度
- 删除确认补充影响说明。

### 2. 黑话词典双工作台信息前置

- 为 `Slang` 增加页内说明，明确：
  - 黑话条目页负责维护词条内容
  - 分组页只维护归类与排序
  - 删除条目和删除分组各自的影响面
- 增加 4 张摘要卡，前置展示：
  - 分组总量
  - 词条总量
  - 当前页词条数
  - 当前工作台
- 把 Tabs 收成受控状态，用于同步首屏摘要中的当前工作台说明。
- 为黑话与分组的创建 / 编辑弹窗补充字段边界提示，并把分组页的英文空态改成中文。
