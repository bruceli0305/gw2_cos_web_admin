# Round 38 - Batch AG - 后台首页看板问题审查

## 范围

本轮不改业务代码，只审查当前后台首页看板与壳层菜单的实际问题。

检查依据：

- 用户提供的后台首页截图
- `src/layouts/BasicLayout.tsx`
- `src/pages/Dashboard/index.tsx`

## 结论

### 1. [P1] 菜单分组在当前实现下被整体吃掉，超级管理员首页只剩两个顶层入口

表现：

- 截图左侧菜单只剩：
  - `首页看板`
  - `交易所观察`
- 其它分组如：
  - 社区内容
  - 翻译与词典
  - 游戏数据
  - 权限与审计
  已经完全不可见。

根因：

- `BasicLayout.tsx` 当前菜单分组节点不再带 `path`，见 `src/layouts/BasicLayout.tsx:82`, `:91`, `:99`, `:113`
- 之前为修“单子权限账号看不到入口”又加入了“单子项提升”逻辑，见 `src/layouts/BasicLayout.tsx:124-137`
- 但从当前截图结果看，`ProLayout` 在当前 `mix` 布局下并没有把这些无 `path` 的父分组稳定渲染出来，最终只剩原本就有顶层 `path` 的：
  - `/dashboard`
  - `/data/market-watch`

影响：

- 这是高严重度导航回归。
- 超级管理员都无法从菜单进入绝大多数后台页面，普通管理员也会更严重。

### 2. [P2] 首页中文界面仍在使用浏览器默认英文日期格式，语言体验断裂

表现：

- 截图里出现：
  - `3/31/2026`
  - `11:27:40 AM`
- 与中文后台整体视觉不一致。

根因：

- `formatTimestamp()` 直接调用 `toLocaleString()`，未固定中文 locale，见 `src/pages/Dashboard/index.tsx:68-70`
- 今日日期也直接调用 `new Date().toLocaleDateString()`，见 `src/pages/Dashboard/index.tsx:320` 和 `:480`

影响：

- 页面语言已经统一为中文，但时间格式仍随浏览器/系统 locale 漂移。
- 在中文管理后台里会持续出现中英混排。

### 3. [P2] 超级管理员侧栏脚注把“全权访问”显示成“0 项权限”，语义错误

表现：

- 截图左下角当前管理员卡片显示：
  - `超级管理员`
  - `0 项权限`

根因：

- `permissionCount` 直接取 `me.permissions.length`，见 `src/layouts/BasicLayout.tsx:76`
- 但超级管理员走的是 `isSuper` 直通逻辑，权限不依赖显式列表，见 `src/layouts/BasicLayout.tsx:56-61`

影响：

- 页面向管理员传递了错误语义。
- 这不是“数据为空”，而是“超级管理员不应按显式权限条目数表达”。

### 4. [P3] 首页底部两张卡片没有做真正的等高策略，视觉重心失衡

表现：

- 截图底部左侧“数据就绪情况”明显短于右侧“当前快照”，形成大面积留白与卡片高度不齐。

根因：

- 页面在多个 `Col` 上使用 `display: flex`，卡片本身只设置 `height: '100%'`，见 `src/pages/Dashboard/index.tsx:77-85`
- 但没有给卡片本身或列容器建立稳定的 `flex: 1` 拉伸策略，导致实际高度仍由内容撑开
- 对应布局见：
  - `src/pages/Dashboard/index.tsx:454-488`

影响：

- 首页看板在视觉上不够稳定。
- 当前快照和数据就绪情况本应是一组平级摘要卡，但现在呈现为一高一矮。

### 5. [P3] KPI 卡片的语义不完全一致，第四张卡会误导

表现：

- 第四张卡标题是“招募内容”，主值显示 `raid` 数量
- 但底部 meta 又显示“内容总量 439 条”

根因：

- `overviewCards` 第四项把“团本招募数”和“整体内容库存总量”混在同一张卡里，见 `src/pages/Dashboard/index.tsx:172-179`

影响：

- 用户会误以为这张卡代表“整体内容库”而不是“团本招募”。
- 与前 3 张 KPI 卡“一张卡只表达一个核心指标”的模式不一致。

## 本轮未改动代码

本轮仅完成审查与定位，没有提交运行时代码修复。

## 建议修复顺序

1. 先修菜单分组回归
2. 再统一首页日期/时间 locale
3. 然后修超级管理员权限计数表达
4. 最后收首页卡片等高和 KPI 语义

## 风险

1. 本轮未启动浏览器自动化，仅基于截图和源码确认问题。
2. 菜单回归已经在截图中直接可见，优先级高于首页视觉细节。
